# 数学・アルゴリズム 200本カリキュラム ロードマップ

「数学（高校〜大学レベル）」と「アルゴリズム」を横断する、全200本の動画カリキュラムの構成表です。
既存の `project/math/`（30秒〜1分の短尺シリーズ）とは別チャンネル/別シリーズとして設計しています。

## 前提条件

- **本数**: 200本
- **1本の長さ**: 5〜10分（既存の短尺シリーズより長く、1本＝1レッスン相当）
- **制作ツール**: Manim（Python）
- **言語**: 日本語（`manim_math/japanese.py` の `ja_text` / `ja_tex` を継承利用）
- **レベル**: 高校数学 〜 大学数学、およびアルゴリズム（入門〜中級）
- **ナレーション / BGM / 背景**: 今回のロードマップでは対象外（後続フェーズで検討）
- **状態**: 全て `未着手`（このロードマップは構成案であり、実装はこれから）

## 全体構成

| Part | 内容 | 本数 | 番号範囲 |
|---|---|---|---|
| A | 高校数学 | 70 | #1–#70 |
| B | 大学数学 | 60 | #71–#130 |
| C | アルゴリズム・データ構造 | 70 | #131–#200 |

推奨する視聴順は番号どおり（#1→#200）ですが、各セクションは比較的独立しているため、
高校数学が既習の視聴者は Part B や Part C から見始めても支障がないように構成しています。

## 依存関係・視聴順の指針

- **Part A（高校数学）**は数I・A・II・B・III・Cの標準的な学習順に対応。A1→A11の順に前提知識が積み上がる。
- **Part B（大学数学）**はPart Aの完了を前提とする。B1・B2（微積分の深化）とB3（線形代数）は並行して視聴可能。B4〜B8は各章がB1〜B3に依存するが、章同士の依存は薄い。
- **Part C（アルゴリズム）**はC1（計算量の基礎）を最初に必ず視聴する。C2（データ構造）はC3以降の前提。C6（グラフ）はC2（木構造・ヒープ・Union-Find）を前提とする。C7（動的計画法）はC5（再帰）の後に置く。
  数学的な前提はほぼ高校数学（Part A）レベルで足りるため、Part B を経ずに Part C に進んでも学習可能。

## 制作方針（今後の実装に向けたメモ）

- 既存の日本語ヘルパー `manim_math/japanese.py`（`ja_text`, `ja_tex`, `JapaneseScene`）を継承利用する。
  ただし本シリーズは1本5〜10分と長いため、既存の `PacedScene`（30〜60秒想定、`motion_scale=2.5`）は使わず、
  新たに `LessonScene`（仮称、`motion_scale=1.0` 程度）のような基底クラスを別途用意するのが妥当。
- 日本語は `ja_text` で表示し、`MathTex` / `ja_tex` 側には日本語を混在させない方針を踏襲する（既存 README のチェック項目と同様）。
- ディレクトリ構成は既存の `project/math/` に合わせ、例えば `project/curriculum_200/{A|B|C}_<番号3桁>_<スラッグ>/{scene.py, storyboard.md}` のような形を想定。
- 1本あたりの構成は「見出し→具体例の提示→図解・アニメーションによる直感→定義/定理の提示→導出→まとめ」の6段構成を目安にし、
  5〜10分の尺を待機時間ではなく可視化・途中式のアニメーションで埋める（既存シリーズの「不自然な待ち時間で尺を稼がない」方針を継続）。
- ナレーション・BGM・背景（色/テーマ）は本ロードマップの対象外。字幕・音声・配色は制作フェーズで別途検討する。
