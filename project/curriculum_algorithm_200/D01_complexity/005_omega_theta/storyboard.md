## 1:00 STEP 1 ビッグOは上からの抑え

見出しチップ: 「STEP 1  ビッグO」

説明1:

> 前回まで使っていた O は、「ある定数倍より上に出ない」という意味。

式を一段ずつ:

- \(T(n)=n\)
- 定数 \(C=1\) を取る
- \(n \le 1\cdot n\) が、すべての n≥1 で成り立つ
- よって \(n=O(n)\)

説明2:

> もっと大きい型でも、上から抑えられる。

- \(n \le n^2\) が n≥1 で成り立つ
- よって \(n=O(n^2)\) でも正しい
- ただし、これはゆるい

定義を出して、長めに残す:

> T(n)=O(f(n)) は、十分大きい n で T(n) ≤ C·f(n) となる定数 C がある、という意味。

下:

> O は「これより速くは増えない」。遅くないことの証明にはなるが、遅さの下限ではない。

---

## 2:20 STEP 2 Ωは下からの抑え

見出しチップ: 「STEP 2  オメガ」

説明1:

> 下からも抑えたいときは、Ω を使う。「少なくともこれくらいは増える」。

式を一段ずつ（T(n)=n）:

- 下から定数倍で挟む
- \(n \ge 1\cdot n\) が n≥1 で成り立つ
- よって \(n=\Omega(n)\)

説明2:

> n は n^{2} の下からは抑えられない。

- 「すべての十分大きい n で \(n \ge C\cdot n^2\)」となる C>0 はあるか
- n=10 なら \(10 \ge C\cdot 100\)、つまり C≤0.1
- n=100 なら \(100 \ge C\cdot 10000\)、つまり C≤0.01
- n を大きくすると、許される C はどんどん小さくなる
- 一つの固定した C では、いつまでも成り立たない
- よって \(n \neq \Omega(n^2)\)

定義を出して、長めに残す:

> T(n)=Ω(f(n)) は、十分大きい n で T(n) ≥ C·f(n) となる定数 C>0 がある、という意味。

下:

> Ω は「これより遅くは増えない」。仕事が消えないことの下限。

---

## 3:50 STEP 3 Θは両方つくとき

見出しチップ: 「STEP 3  シータ」

説明1:

> 上からも下からも、同じ型で抑えられるとき、Θ と書く。

T(n)=n について:

- \(n=O(n)\) かつ \(n=\Omega(n)\)
- よって \(n=\Theta(n)\)

不等式を一段ずつ:

- 定数 \(c_1=1,\ c_2=1\) を取る
- \(c_1\cdot n \le n \le c_2\cdot n\)
- つまり \(n \le T(n) \le n\)

定義を出して、長めに残す:

> T(n)=Θ(f(n)) は、T(n)=O(f(n)) かつ T(n)=Ω(f(n)) のとき。増え方が f(n) の型そのもの。

下:

> Θ が書けるなら、O だけより情報が厚い。「その速さで増える」と言ってよい。

## 5:20 STEP 4 どれを書くか

見出しチップ: 「STEP 4  使い分け」

表（列は左揃え）:

| 書き方 | 意味 | T=n の例 |
|---|---|---|
| \(O(n)\) | 上から n で抑える | 正しい（きつい） |
| \(O(n^2)\) | 上から n^{2} で抑える | 正しい（ゆるい） |
| \(\Omega(n)\) | 下から n で抑える | 正しい |
| \(\Theta(n)\) | 上下とも n | 正しい |
| \(\Theta(n^2)\) | 上下とも n^{2} | 正しくない |

説明:

> 日常の「オーダーは n」は、だいたい Θ(n) のつもり。O(n^{2}) とだけ書くと、本当は n かもしれない。

下:

> きつい型が分かるなら Θ。上だけしか言えないなら O。下だけなら Ω。

## 6:50 実例 3n+5 を上と下から抑える

見出しチップ: 「実例  3n+5」

対象: \(T(n)=3n+5\)

### 上から（O）

途中を飛ばさない。

- \(3n+5 \le 3n+5n\) （n≥1 のとき 5≤5n）
- \(=8n\)
- 定数 C=8 で \(T(n)\le 8n\)
- よって \(T(n)=O(n)\)

### 下から（Ω）

- \(3n+5 \ge 3n\)
- 定数 C=3 で \(T(n)\ge 3n\)
- よって \(T(n)=\Omega(n)\)

### 両方（Θ）

- \(3n \le 3n+5 \le 8n\) （n≥1）
- よって \(T(n)=\Theta(n)\)

n=1 と n=4 を代入して検算。飛ばさない。

- n=1: \(3+5=8\)。下は 3、上は 8。8 は 3 以上 8 以下
- n=4: \(12+5=17\)。下は 12、上は 32。17 は 12 以上 32 以下

下:

> 定数と小さい項を落としたあと、上下が同じ型なら Θ。前回の「落として O(n)」は、実は Θ(n) だった。
