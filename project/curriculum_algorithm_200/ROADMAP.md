# アルゴリズム 200本カリキュラム ロードマップ

高校レベル〜大学レベルを対象にした、**アルゴリズム単独で200本**の動画カリキュラムの構成表です。
`project/curriculum_math_200/ROADMAP.md`（数学200本）とは独立したシリーズです。
数学的な前提はほぼ高校数学（`curriculum_math_200` の Part A）レベルで足ります。

## 前提条件

- **本数**: 200本（アルゴリズム・データ構造のみ）
- **1本の長さ**: 5〜10分
- **制作ツール**: Manim（Python） / **言語**: 日本語（`manim_math/japanese.py` の `ja_text` / `ja_tex` を継承利用）
- **レベル**: 高校レベル（初級プログラミング経験を想定）〜 大学の「アルゴリズムとデータ構造」講義＋競技プログラミング入門レベル
- **ナレーション / BGM / 背景**: 今回のロードマップでは対象外（後続フェーズで検討）
- **状態**: 全て `未着手`（構成案であり、実装はこれから）

## 依存関係・視聴順の指針

- **D1（導入・計算量）**を最初に必ず視聴する。全ての章の前提になる。
- **D2（基本データ構造）**はD3以降・D9・D12の前提。特に木構造・ヒープ・Union-Findは必須。
- **D4（ソート）・D5（探索）**はD2の後に置くと理解しやすいが、D1の直後に視聴しても問題ない。
- **D6（再帰・分割統治）**はD10（動的計画法）・D14（計算幾何学の一部）の前提となる。
- **D7・D8・D9（グラフ関連）**はD2（特に木構造・ヒープ・Union-Find）とD6（再帰）を前提とする。D8→D9の順が推奨。
- **D10（動的計画法）**はD6（再帰）の後に置く。D9（グラフ）の後だとビットDP・木DPの理解がスムーズ。
- **D13（数論アルゴリズム）・D14（計算幾何学）**は数学的な前提（`curriculum_math_200` の A10 整数の性質、A11 ベクトル）と合わせて視聴すると理解が深まるが、必須ではない。
- **D15（NP完全性）**はD7〜D11の内容（具体的な問題例）を前提とする。
- **D16〜D19**は発展トピックであり、D1〜D15を終えた後の任意の順で視聴可能。
- **D20（総合演習）**は最終章として全体を振り返る。

## 制作方針（今後の実装に向けたメモ）

- 既存の日本語ヘルパー `manim_math/japanese.py`（`ja_text`, `ja_tex`, `JapaneseScene`）を継承利用する。
  ただし本シリーズは1本5〜10分と長いため、既存の `PacedScene`（30〜60秒想定、`motion_scale=2.5`）は使わず、
  新たに `LessonScene`（仮称、`motion_scale=1.0` 程度）のような基底クラスを別途用意するのが妥当。
- アルゴリズムの動作過程（配列の要素の入れ替え、ポインタの移動、グラフの探索順序など）は
  Manim の `VGroup` / `Indicate` / `Transform` 等でステップごとに可視化し、擬似コードと図解を並置する構成を想定する。
- 日本語は `ja_text` で表示し、`MathTex` / `ja_tex` 側には日本語を混在させない方針を踏襲する。
- ディレクトリ構成は既存の `project/math/` に合わせ、例えば
  `project/curriculum_algorithm_200/D<番号2桁>_<番号3桁>_<スラッグ>/{scene.py, storyboard.md}` のような形を想定。
- 1本あたりの構成は「見出し→具体例（小さな入力）→ステップごとの可視化→計算量の議論→擬似コード→まとめ」の6段構成を目安にする。
