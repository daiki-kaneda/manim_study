## 3:20 工夫 STEP 1 差は \(10^{-n}\)

対比を消す。左上に「STEP 1  差の式」。

本文:

- 「有限桁のほうを、記号で書いてみます。」

途中式（残す）:

1. \(n\) 個の 9 を並べた数を \(a_n\) と書く
2. \(a_1=0.9,\ a_2=0.99,\ a_3=0.999\)
3. \(1-a_n=10^{-n}\)
4. 検算: \(n=1\) なら \(10^{-1}=0.1\)。表の差と同じ
5. 検算: \(n=3\) なら \(10^{-3}=0.001\)。これも同じ

下:

- 「止めた位置が \(n\) なら、残りはいつも \(10^{-n}\) です。」
- 「『差が残る』は正しい。問題は、\(n\) を止めずに進めたときです。」

定義の式 \(1-a_n=10^{-n}\) は 3 秒以上残す。

## 4:40 工夫 STEP 2 数直線で近づく

\(0.85\) から \(1.05\) までを拡大した数直線を画面中央に置く。右端に \(1\) の印を先に出す。

青い点を順に動かす。前の位置は薄く残す。今の点と \(1\) のあいだに差のブレースを付け、差の式を下に出す。飛ばさない。

1. \(0.9\)（差 \(1-0.9=0.1\)）
2. \(0.99\)（差 \(1-0.99=0.01\)）
3. \(0.999\)（差 \(1-0.999=0.001\)）
4. 点が \(1\) に重なり、差は \(1-1=0\)

\(0.99\) と \(0.999\) は \(1\) のすぐ左に寄るので、ラベルは点の下にずらして重ねない。

下:

- 「点は \(1\) にどんどん近づきます。」

式を残す:

\[
\lim_{n\to\infty}(1-a_n)=\lim_{n\to\infty}10^{-n}=0
\]

この式はあとで使うので、出したあとすぐ消さない（3 秒以上）。

## 8:30 実例 最初から最後まで通す

工夫の式を消す。左上に「実例」。

小さな具体例を、最初から最後まで通す。新しい数は出さない。\(0.999\ldots\) だけを辿る。

画面にチェックを順に残す。

1. 有限: \(1-0.9=0.1,\ 1-0.99=0.01,\ 1-0.999=0.001\)
2. 一般: \(1-a_n=10^{-n}\)
3. 極限: \(n\to\infty\) で差は 0
4. 別計算: \(10x-x\) でも等比級数でも \(x=1\)

下:

- 「『差が残る』は、止めたときの話でした。」
- 「止めないときの差は 0 なので、二つの書き方は同じ数です。」

## 9:30 一般化 無限小数は極限

実例を消す。左上に「一般化」。

本文を一段ずつ残す。

1. 「今やったことは、無限小数を極限として読む、ということでした。」
2. 「\(0.999\ldots\) は、『9 を \(n\) 個書いた数』の、\(n\) を限りなく進めた先です。」
3. 「その先では差 \(10^{-n}\) が 0 になるので、\(1\) と同じ実数です。」
4. 「書き方が二つあっても、指している数は一つ、ということがあります。」

式を残す（すぐ消さない）:

\[
0.999\ldots\ :=\ \lim_{n\to\infty}a_n=\lim_{n\to\infty}(1-10^{-n})=1
\]

\(\varepsilon\)–\(\delta\) は出さない。高校の極限の言葉で閉じる。

## 10:20 まとめ

一般化を消す。左上に「まとめ」。

持ち帰れる型だけ。次回必見にはしない。

1. 有限個の 9 を 1 から引くと、差 \(10^{-n}\) が残る
2. 9 を止めずに進めると、その差は 0 に収束する
3. だから \(0.999\ldots\) と \(1\) は同じ数
4. 無限小数は、「どこまでも続く桁」の極限として読む

- 「循環小数が分数になる話も、同じ読み方で閉じます。」

「先に別の回を見ること」とは書かない。
