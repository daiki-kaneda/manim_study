## 0:00 問い

見出し「周が同じなら、いちばん広い長方形は」を中央に出してから上へ固定する。

左に細い長方形、右にやや正方形に近い長方形。両方の周は同じ、と後で言う。答えはすぐ出さない。

寸法は図の辺に付ける。式だけ右に並べない。

- 下辺（橙）: 「横」
- 左辺（黄）: 「縦」

下に問いを出す。

- 「同じ長さのひもで、長方形の畑を囲います。」
- 「周が同じなら、いちばん広い縦横は何でしょう。」

ねらい: 細長い方が広いのか、真ん中が広いのか、試したくなるようにする。

## 0:40 試行 細長い畑

カードを消す。左上に「試行  細長い」。

本文:

- 「まず、極端に細長い長方形を描いてみます。」

周 \(2(x+y)=20\)、つまり \(x+y=10\) に固定する。この条件は画面に残す。

1. 横 \(1\)、縦 \(9\) の長方形。面積 \(1\times 9=9\)
2. 横 \(2\)、縦 \(8\)。面積 \(2\times 8=16\)
3. 横 \(3\)、縦 \(7\)。面積 \(3\times 7=21\)

各段階で、横は下辺、縦は左辺に Brace。「横」「縦」の語を式の左に書く。面積は図の右に出す。飛ばさない。

下:

- 「細長いほど、面積は小さいです。」
- 「正方形に近づけると、増えていきます。」

ここでは最大の式は出さない。

## 1:50 試行 整数の縦横を試す

細長い図を消す。左上を「試行  整数」に替える。

本文:

- 「横を整数にして、面積を全部書いてみます。」

先に \(x=4\) だけ、途中式を残す。

1. \(y=10-4=6\)
2. \(4\times 6=24\)

そのあと比較表（`MathTable`、列は左揃え）。行を上から順に出す。途中を飛ばさない。

| 横 \(x\) | 縦 \(10-x\) | 面積 \(xy\) |
|---|---|---|
| \(1\) | \(9\) | \(9\) |
| \(2\) | \(8\) | \(16\) |
| \(3\) | \(7\) | \(21\) |
| \(4\) | \(6\) | \(24\) |
| \(5\) | \(5\) | \(25\) |
| \(6\) | \(4\) | \(24\) |

下:

- 「整数では、\(5\) と \(5\) がいちばん大きい。」
- 「でも整数以外は試していません。」
- 「\(4.5\) と \(5.5\) の方が、大きいかもしれません。」

この直観は消さずに残す。ここでは公式を出さない。素朴な試し方が、ここで止まる。

## 3:10 工夫 STEP 1 周が一定なら和が一定

表を消す。左上に「STEP 1  記号」。

本文:

- 「周が決まっている、ということを式にします。」

途中式を一段ずつ残す。

1. 横を \(x\)、縦を \(y\) と書く
2. 周は \(2(x+y)=L\)
3. よって \(x+y=L/2\)
4. この和を \(s\) とおく。\(s=L/2\)
5. 面積 \(S=xy=x(s-x)\)

定義の式 \(x+y=s\) と \(S=x(s-x)\) は 3 秒以上残す。

下:

- 「残る問いは、\(x\) を動かしたとき \(S\) がいちばん大きくなる場所です。」

微分の記号は出さない。

---

## 4:00 工夫 STEP 2 平方完成

記号の本文を消す。左上に「STEP 2  平方完成」。

本文:

- 「二次式を、平方の差の形に直します。」

途中式を一段ずつ残す。飛ばさない。

1. \(S=x(s-x)\)
2. \(S=sx-x^2\)
3. \(S=-(x^2-sx)\)
4. \(x^2-sx\) に \((s/2)^2\) を足して引く
5. \(S=-\bigl(x^2-sx+(s/2)^2-(s/2)^2\bigr)\)
6. \(S=-\bigl((x-s/2)^2-s^2/4\bigr)\)
7. \(S=s^2/4-(x-s/2)^2\)

最後の式は 3 秒以上残す。

観察:

- \((x-s/2)^2\) は 0 以上
- だから \(S\) は \(s^2/4\) を超えない
- 差が 0 になるのは \(x=s/2\) のとき
- そのとき \(y=s-x=s/2\)

下:

- 「いちばん広いのは、横と縦が等しいときです。正方形です。」

---

## 5:20 工夫 STEP 3 相加相乗

平方完成を消す。左上に「STEP 3  相加相乗」。

本文:

- 「同じ結論を、平方が 0 以上であることからも出せます。」

途中式を一段ずつ。\(\sqrt{x}\)、\(\sqrt{y}\) は正として進む（\(x>0\)、\(y>0\)）。

1. \(\bigl(\sqrt{x}-\sqrt{y}\bigr)^2\ge 0\)
2. \(x+y-2\sqrt{xy}\ge 0\)
3. \(x+y\ge 2\sqrt{xy}\)
4. 両辺は 0 以上なので、2 で割る。\((x+y)/2\ge\sqrt{xy}\)
5. 両辺は 0 以上なので、平方してよい。\(\bigl((x+y)/2\bigr)^2\ge xy\)
6. \(s^2/4\ge S\)

等号:

- \(\sqrt{x}=\sqrt{y}\) のとき
- よって \(x=y\)

式 \(s^2/4\ge S\) は 3 秒以上残す。名前はここでは急がない。

「同様に」で平方を飛ばさない。両辺が 0 以上だから平方してよい、と一段残す。

---

## 6:30 工夫 STEP 4 正方形へ動かす

相加相乗を消す。左上に「STEP 4  動かす」。

本文:

- 「周を保ったまま、横を動かします。」

同じ周 \(x+y=s\) の長方形を、細長いところから正方形へ、さらに縦長へ動かす。飛ばさない。

各段階で残すもの:

- 下辺に「横」\(x\)（橙）
- 左辺に「縦」\(s-x\)（黄）
- 右に面積 \(S=x(s-x)\)

下に式を残す。

1. 細長いと \((x-s/2)^2\) が大きいので \(S\) は小さい
2. \(x=s/2\) で差が消え、\(S=s^2/4\)
3. 反対側へ行き過ぎても、また小さくなる

最後の \(S=s^2/4\) は 3 秒以上残す。

図の上にキャプションを重ねない。左に図、右に式。

---

## 7:30 実例 周 20

工夫の式を消す。左上に「実例」。

小さな具体例を最初から最後まで通す。周は \(20\)。\(s=10\)。新しい定数は出さない。

本文:

- 「周 20 のひもで、整数で止まった疑いを、式で確かめます。」

先に \(x=4.5\) だけ、途中式を残す。

1. \(y=10-4.5=5.5\)
2. \(4.5\times 5.5=4.5\times(5+0.5)\)
3. \(4.5\times 5=22.5\)
4. \(4.5\times 0.5=2.25\)
5. \(22.5+2.25=24.75\)
6. 正方形なら \(5\times 5=25\)
7. \(25-24.75=0.25=(4.5-5)^2\)

平方完成の式と一致することを、一段残す。

\[
S=25-(x-5)^2
\]

そのあと比較表（`MathTable`、列は左揃え）。行を上から順に出す。

| 横 \(x\) | 縦 \(10-x\) | 面積 \(xy\) |
|---|---|---|
| \(4\) | \(6\) | \(24\) |
| \(4.5\) | \(5.5\) | \(24.75\) |
| \(5\) | \(5\) | \(25\) |
| \(5.5\) | \(4.5\) | \(24.75\) |
| \(6\) | \(4\) | \(24\) |

下:

- 「\(4.5\) は \(5\) より小さい。」
- 「ずれの平方のぶんだけ、面積が落ちます。」
- 「周 20 なら、いちばん広いのは 5 かける 5 の正方形です。」

---

## 8:40 一般化 和一定なら積は等しいとき最大

実例を消す。左上に「一般化」。

本文を一段ずつ残す。

1. 「今やったことは、平方完成と、相加相乗平均の不等式でした。」
2. 「和 \(x+y\) が一定なら、積 \(xy\) は \(x=y\) のとき最大です。」
3. 「相加平均は相乗平均以上。等号は \(x=y\) のとき。」
4. 「制約の下でいちばんよい値を探す、という型でもあります。」

式を残す（すぐ消さない）:

\[
\dfrac{x+y}{2}\ge\sqrt{xy},\qquad xy\le\Bigl(\dfrac{x+y}{2}\Bigr)^2
\]

最後の不等式は 3 秒以上残す。微分の講義にはしない。

---

## 9:30 まとめ

一般化を消す。左上に「まとめ」。

持ち帰れる型だけ。次回必見にはしない。

1. 周が一定なら、横と縦の和が一定
2. 細長い長方形は面積が小さい。整数だけ試すと、正方形の隣が疑わしく残る
3. 平方完成すると、ずれの平方のぶんだけ面積が落ちる
4. だからいちばん広い長方形は正方形

関連する別の問い（依存を作らない紹介）:

- 「周が同じでも、長方形に限らなければ、もっと広い形があります。」

「先に別の回を見ること」とは書かない。
