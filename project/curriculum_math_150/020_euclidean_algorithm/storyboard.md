## 0:50 試行 小さい数で割る

左上に「試行  小さい数」。

本文:

- 「まず、小さい素数から順に、両方を割り切るか試します。」

途中:

1. \(2\) で割る。どちらも奇数なので外れます
2. \(3\) で割る。各位の和: \(1+2+3+4+5+6+7=28\)。\(28\) は \(3\) で割れない。左は外れます
3. \(5\) で割る。一の位が \(7\) と \(1\) なので外れます
4. \(11\) で割る。右の \(891011\div 11=81001\)。左の \(1234567\div 11\) は割り切れません

表。列は左揃え。

| 割る数 | \(1234567\) | \(891011\) |
|---|---|---|
| \(2\) | 外れ | 外れ |
| \(3\) | 外れ | |
| \(5\) | 外れ | 外れ |
| \(11\) | 外れ | 割れる |

下:

- 「片方だけ割れる数では、公約数になりません。」
- 「素因数が 100 を超えると、順に割る方法は現実的ではありません。」

よくある誤解（小さい数から試せばすぐ出る）を否定する。左は \(127\times 9721\) ですが、ここではまだ分解しません。共感: 巨大だと、素因数分解は辛く感じます。

## 2:00 試行 引き算を繰り返す

左上を「試行  引き算」に替える。

本文:

- 「大きい方から小さい方を引く操作を、公約数を保ったまま繰り返してみます。」

小さい例を先に最後まで。

- \(48\) と \(18\)
- \(48-18=30\)
- \(30-18=12\)
- \(18-12=6\)
- \(12-6=6\)
- \(6-6=0\)。残った \(6\) が、両方を割り切る最大です

図: 長い棒 \(48\) から短い棒 \(18\) を繰り返し除く。説明は図の右。図の上にキャプションを重ねない。

大きい数へ戻す。

- \(1234567-891011=343556\)。1 回で済む
- あとで出る段では、\(2785\) から \(11\) を引く回数が \(253\) 回です

下:

- 「引き算でも答えは出ますが、商が大きい段では回数が膨らみます。」
- 「同じ引き算をまとめて済ませる方法が、余りです。」

ここでは互除法の名前は出さない。

## 3:10 工夫 STEP 1 公約数

左上を「STEP 1  公約数」。

本文:

- 「両方を割り切る正の整数の、いちばん大きいものを記号にします。」

記号は「とおく」。ユークリッドの名前は使わない。

1. 正の整数 \(a\) と正の整数 \(b\) とおく。いま \(a\ge b\) とします
2. \(d\) が \(a\) も \(b\) も割り切るとき、\(d\) を公約数とおく
3. そのような \(d\) のうち最大を、最大公約数とおく。記号は \(\gcd(a,b)\)

\(48\) と \(18\) で戻る。

- \(18=2\cdot 3^{2}\)、\(48=2^{4}\cdot 3\)
- 共通の素因数は \(2\) と \(3\)。最大は \(2\cdot 3=6\)
- だから \(\gcd(48,18)=6\)

下:

- 「素因数がすぐ書けるときだけ、この確かめは簡単です。」
- 「巨大な 2 数では、素因数を先に出す必要がないやり方を次で見ます。」

## 4:20 工夫 STEP 2 差も割れる

左上を「STEP 2  差」。

本文:

- 「公約数は、差も割り切ることを式で残します。」

入口は \(d\) が \(a\) も \(b\) も割り切ること。画面に「入口で再掲します」とは書かない。

途中式を省かない。

- \(a=d\cdot m\)、\(b=d\cdot n\) とおく。\(m,n\) は整数です
- \(a-b=d\cdot m-d\cdot n=d(m-n)\)
- だから \(d\) は \(a-b\) も割り切る
- 同じ理由で、\(d\) は \(a-qb\) も割り切る。\(q\) は整数です

\(48\) と \(18\):

- \(48-18=30\)。\(6\) は \(30\) も割り切る
- \(30-18=12\)。\(6\) は \(12\) も割り切る

下:

- 「共通の約数は、引いても消えません。」
- 「だから大きい方を小さい方に取り替えても、最大公約数は変わりません。」

合同式の記号はまだ出さない。

## 5:30 工夫 STEP 3 余りに替える

左上を「STEP 3  余り」。

本文:

- 「引き算を何回もする代わりに、割り算の余りへ一気に替えます。」

- \(a\) を \(b\) で割った商を \(q\)、余りを \(r\) とおく
- \(a=qb+r\)。余りは \(0\le r<b\)
- STEP 2 より、\(d\) が \(a\) と \(b\) を割り切るなら、\(d\) は \(r=a-qb\) も割り切る
- 逆に、\(d\) が \(b\) と \(r\) を割り切るなら、\(d\) は \(a=qb+r\) も割り切る
- だから \(\gcd(a,b)=\gcd(b,r)\)

\(48\) と \(18\):

- \(48=2\cdot 18+12\)。余り \(12\)
- \(\gcd(48,18)=\gcd(18,12)\)
- \(18=1\cdot 12+6\)。余り \(6\)
- \(\gcd(18,12)=\gcd(12,6)\)
- \(12=2\cdot 6+0\)。余り \(0\)

下:

- 「余りへ替えても、最大公約数は同じです。」
- 「情報が落ちる、という心配は、この等式では支えられません。」

よくある誤解（余りにすると約数の情報が消える）を否定する。

合同式をここで導入してよい。

- \(a\equiv r\pmod{b}\) と書くと、\(a\) と \(r\) は \(b\) で割った余りが同じ、という意味です
- だから \(\gcd(a,b)=\gcd(b,a\bmod b)\)

## 6:40 工夫 STEP 4 余り 0 で止まる

左上を「STEP 4  停止」。

本文:

- 「余りが 0 になった直前の割る数が、最大公約数です。」

1. 組 \((a,b)\) を \((b,r)\) に替える
2. \(r=0\) なら、直前の \(b\) が答え
3. 余りは毎回真に小さくなるので、いつか 0 に着きます

\(48\) と \(18\) の表。列は左揃え。

| \(a\) | \(b\) | \(q\) | \(r\) |
|---|---|---|---|
| \(48\) | \(18\) | \(2\) | \(12\) |
| \(18\) | \(12\) | \(1\) | \(6\) |
| \(12\) | \(6\) | \(2\) | \(0\) |

下:

- 「最後に余り 0 を出した \(6\) が、\(\gcd(48,18)\) です。」
- 「素因数分解を経由していません。」

## 7:40 実例 1234567 と 891011

左上を「実例」。

本文:

- 「問いの 2 数を、余りへ替える手順で最後まで通します。」

途中を飛ばさない。商と余りを一段ずつ。画面に一度に出しきれない段は、先の段を消してから続きを出す。

- \(1234567=1\cdot 891011+343556\)
- \(891011=2\cdot 343556+203899\)
- \(343556=1\cdot 203899+139657\)
- \(203899=1\cdot 139657+64242\)
- \(139657=2\cdot 64242+11173\)
- \(64242=5\cdot 11173+8377\)
- \(11173=1\cdot 8377+2796\)
- \(8377=2\cdot 2796+2785\)
- \(2796=1\cdot 2785+11\)
- \(2785=253\cdot 11+2\)
- \(11=5\cdot 2+1\)
- \(2=2\cdot 1+0\)

最後の 0 でない余りは \(1\)。だから最大公約数は \(1\) です。

表は後半だけ残す。列は左揃え。

| \(a\) | \(b\) | \(q\) | \(r\) |
|---|---|---|---|
| \(2796\) | \(2785\) | \(1\) | \(11\) |
| \(2785\) | \(11\) | \(253\) | \(2\) |
| \(11\) | \(2\) | \(5\) | \(1\) |
| \(2\) | \(1\) | \(2\) | \(0\) |

下:

- 「商 \(253\) の段は、引き算なら 253 回です。余りなら 1 行です。」
- 「2 数は互いに素です。共通の素因数はありません。」

あとで素因数を書いて確かめてよい。\(1234567=127\times 9721\)、\(891011=11\times 81001\)。共通因子は 1 だけ。

## 8:40 一般化 互除法

左上を「一般化」。

本文:

- 「今やったことは、ユークリッドの互除法と呼ばれる手順でした。」

主張を式で書く。正の整数 \(a,b\) とします。

- \(\gcd(a,b)=\gcd(b,a\bmod b)\)
- \(a\bmod b=0\) なら \(\gcd(a,b)=b\)
- 割り算の余りへ替える操作を、余り 0 まで繰り返す

一次不定方程式への入口。

- \(\gcd(a,b)\) を \(d\) とおくと、整数 \(x,y\) で \(ax+by=d\) と書けるものがあります
- \(48\) と \(18\) なら \(d=6\)。\(48\cdot(-1)+18\cdot 3=6\)

下:

- 「巨大でも、余りが小さくなる方向へ進むので、素因数を先に書く必要はありません。」

豆知識: 互いに素、つまり \(\gcd(a,b)=1\) なら、\(ax+by=1\) となる整数 \(x,y\) があります。分数の通分や、余りが 1 になる逆元の入口です。

---

## 9:30 まとめ

左上を「まとめ」。

- 公約数は差も余りも割り切る。だから \(\gcd(a,b)=\gcd(b,a\bmod b)\)
- 余り 0 の直前の割る数が最大公約数
- \(1234567\) と \(891011\) は、余りを 12 段たどると \(1\)
- この手順をユークリッドの互除法とおく

末尾: \(48\cdot(-1)+18\cdot 3=6\) のように、最大公約数は 2 数の整数倍の和でも書けます。
