# 数学 自己完結 150本

高校数学は既知として、**1本だけ見て閉じる**動画の目次です。
`project/curriculum_math_200/`（教科書順の200本）とは別シリーズです。統合しない。番号も混ぜない。

## 視聴契約

- **前提**: 高校数学（数I・A・II・B・III・C の計算と用語）。大学の定義は知らない前提でよい。
- **自己完結**: シリーズ内の別の回を見ていなくても理解できる。必要な道具はその本の中で短く導入する。
- **1本の単位**: 教科書の項目名ではなく、具体的な問い。
- **物語**: 問い → 素朴な試行（失敗や不十分さを残す）→ 工夫して解く → 一般化（定理・考え方）→ まとめ。
- **尺**: 5〜12分目安。途中式を残すことを優先する。目標尺に合わせる空白は置かない。読み時間と画面のポーズは初学者向けに取る（新しい画面 0.5〜1秒、短い式 1〜2秒、式変形 0.5〜1秒、少し複雑な式 2〜3秒、重要な結論 2〜3秒、話題の切り替え 0.5〜1秒）。日本語は省略しすぎない。
- **制作**: Manim、日本語。先に `storyboard.md`、そのあと `scene.py`。基底は `LessonScene`。

グループ分けはプレイリスト用であり、視聴順ではない。どの番号から見てもよい。#101以降のような高度な題材も、厳密な証明ではなく1つの具体例で成立する直感を、自己完結に見せる。

## 1本の型

| パート | 内容 |
|---|---|
| 問い | 具体的で、試したくなる問題。答えはすぐ出さない。 |
| 試行 | 素朴な方法を最後までやり、どこが破綻するかを見せる。 |
| 工夫 | 観察して手順や式を変える。途中式・途中の図は残す。 |
| 一般化 | 「今やったことは、〇〇という定理／考え方だった」 |
| まとめ | 持ち帰れる型だけ。次回必見にはしない。 |

「今回のゴール」は学習項目の箇条書きにしない。「この問いを解く」に限る。「先に #n を見ること」とは書かない。まとめ末尾の一文はなくてもよい。足すなら、いま一般化した事柄の応用例や豆知識に限る。「あれは〇〇の話になります」のようなぼやけた補足は置かない。

## 各本

### 無限・極限・形

### 1. \(0.999\ldots\) は 1 か
- **slug:** `001_repeating_nines`
- **問い:** \(0.999\ldots\) は 1 よりほんの少し小さいのか、同じ数なのか。
- **試行:** 有限桁 \(0.9,\ 0.99,\ 0.999\) を 1 から引いて「差が残る」と感じる。一方 \(1/3=0.333\ldots\) を 3 倍すると \(0.999\ldots=1\) に見える。二つの直観が衝突する。
- **一般化:** 無限小数は「どこまでも続く桁」の極限。差 \(10^{-n}\) は \(n\to\infty\) で 0 に収束するので、二つの表記は同じ実数。
- **仮定:** 分数と無限小数。\(\varepsilon\)–\(\delta\) は出さず、高校の極限の言葉で閉じる。

### 2. 円の面積はなぜ \(\pi r^2\) か
- **slug:** `002_circle_area`
- **問い:** 半径 \(r\) の円の面積が \(r^2\) に比例するとして、比例定数が周の比 \(\pi\) と同じなのはなぜか。
- **試行:** 方眼でマスを数えると近似にしかならない。扇形に切って並べると「だいたい長方形」に見えるが、弧が残る。
- **一般化:** 細い扇を並べると、底辺がほぼ周 \(2\pi r\)、高さが \(r\) の長方形に近づく。取り尽くし（分割を細かくする極限）で面積は \(\pi r^2\)。
- **仮定:** 円周率の定義（周／直径）、扇形と相似。積分の記号は使っても、定義の講義にはしない。

### 3. 周が同じなら、いちばん広い長方形は
- **slug:** `003_fixed_perimeter_rectangle`
- **問い:** ひも 1 本で長方形の畑を囲う。周を固定したとき、面積がいちばん大きくなる縦横は何か。
- **試行:** 細長い長方形は面積が小さい。正方形に近づけると増える。数値をいくつか試して頂点が見える。
- **一般化:** \(x+y\) 一定のとき \(xy\) の最大は \(x=y\)。平方完成、または相加相乗平均。あとで「制約つき最適化」の原型になる。
- **仮定:** 二次関数の最大、または不等式。微分は使ってもよいが必須ではない。

### 4. 鏡を使った最短経路
- **slug:** `004_reflection_shortest_path`
- **問い:** 直線の川に一度触れて、点 A から点 B へ行く最短の折れ線はどこで触れるか。
- **試行:** 触れる点を動かして長さを足す。端に近いほどよさそう、に見えて実は違う。微分で最小を探すと計算が重い。
- **一般化:** B を直線に対して折り返した B' を取り、A から B' の直線が川と交わる点。入射角と反射角が等しい。光の反射と同じ。
- **仮定:** 平面の距離、合同。微分は使わずに幾何で閉じる。

### 5. 立方体の表面を歩く蟻
- **slug:** `005_ant_on_cube`
- **問い:** 立方体の一つの頂点にいる蟻が、反対側の頂点まで表面だけを歩く。最短は空間対角線ではなく、どの面をまたぐ道か。
- **試行:** 辺沿い 3 本は長い。一つの面上の対角線では反対頂点に着かない。どの面を展開するかで長さが変わる。
- **一般化:** 立体の最短経路は展開図上の直線。展開の仕方を列挙し、直線が面の内部を通るものだけが表面の道になる。
- **仮定:** 三平方の定理、展開図。空間ベクトルは使わない。

### 6. 格子点だけで多角形の面積は出るか
- **slug:** `006_picks_theorem`
- **問い:** 方眼紙に頂点が格子点の多角形を描く。内部と境界の点の個数だけから面積は出るか。
- **試行:** 三角形でマスを半分ずつ数えると場合分けが増える。大きい長方形から欠けを引くと、穴の扱いが煩雑。
- **一般化:** ピックの定理 \(S=I+B/2-1\)。頂点が格子点で辺が交わらず穴もない多角形を、内部と境界の格子点を頂点にして面積 \(1/2\) の三角形に分け、オイラーの公式から個数 \(T=2I+B-2\) を導く。
- **仮定:** 三角形の面積。オイラーの公式 \(V-E+F=1\)（多角形の内側）は紹介して認め、途中式を省かずにピックを導く。

### 7. 直線 \(n\) 本で領域は最大いくつか
- **slug:** `007_regions_from_lines`
- **問い:** 平面に直線を 1 本ずつ足す。領域の個数を最大にするには、どう交わせばよいか。最大個数の式は何か。
- **試行:** 全部平行だと増えない。1 点で何本も交わると損。新しい直線が既存のすべてと異なる点で交わるときがいちばん増える。
- **一般化:** \(n\) 本目は \(n\) 本の半直線に切られ、領域を \(n\) 個増やす。漸化式 \(R(n)=R(n-1)+n\) をほどいて \(R(n)=1+n(n+1)/2\)。帰納法の使い方。
- **仮定:** 等差数列の和。帰納法は本編で導入してよい。

### 8. 13 人いれば同じ星座の 2 人がいるか

### 9. 何人集まると誕生日がぶつかるか
- **slug:** `009_birthday_paradox`
- **問い:** 365 日の誕生日で、同じ日の 2 人が出る確率が半を超えるのは何人か。直感の 183 人ではなぜ大きすぎるか。
- **試行:** 「自分と誰かが同じ」だけ数えると過小。全てのペアを数えると、ペアの個数が人の数より速く増える。
- **一般化:** 余事象 \(365\cdot364\cdots(365-n+1)/365^n\)。近似 \(1-e^{-n^2/(2\cdot365)}\)。衝突は \(\sqrt{d}\) のオーダー。ハッシュの衝突と同じ型。
- **仮定:** 独立な一様、指数の近似は「\((1-1/m)^m\approx 1/e\)」の高校知識で導入。

### 10. 残った扉を開けた方がよいか

- **一般化:** 条件付き確率。最初に当たる \(1/3\) は乗り換えで負け、外れる \(2/3\) は司会が残した方が当たり。情報を得たあとの更新。
- **仮定:** 場合分けと分数。ベイズの公式の記号は出さなくてもよい（次の回と独立）。

### 11. 陽性が出ても病気とは限らないのはなぜか
- **slug:** `011_false_positive_bayes`
- **問い:** 1 万人に 1 人の病気、検査の精度が 99% でも、陽性の人が本当に病気である確率はなぜ低くなりうるか。
- **試行:** 「99% 当たるならほぼ病気」と感じる。実際に 1 万人の表を埋めると、偽陽性が本物より多い。
- **一般化:** ベイズの定理。事前の稀さと、検査の偽陽性が事後確率を決める。感度と特異度を分けて読む。

### 12. 二つのサイコロを振って出る目の合計は何が一番多いか

- **問い:** 二つのサイコロを振って出る目の合計は、何が一番多いか。1 個は平坦なのに、足すとなぜ真ん中が膨らむのか。

### 13. 振り続けると表の割合は \(1/2\) に寄るか
- **slug:** `013_law_of_large_numbers`
- **問い:** 公正なコインを振り続けたとき、表の割合は必ず 1/2 に近づくのか。10 回連続表のあともか。
- **試行:** 短い列では大きく外れる。10 回表のあとに「裏が出やすい」と感じる（ギャンブラーの誤り）。差の枚数と割合を混同する。
- **一般化:** 大数の法則。割合は寄るが、差の枚数は揺れうる。独立な試行に記憶はない。

### 14. 針を落として \(\pi\) は出るか
- **slug:** `014_buffons_needle`

- **試行:** 交わる／交わらないを数えると近づくが、なぜ \(\pi\) が出るかは実験だけでは分からない。針の角度と位置を独立に動かす。初めは \(L=D\)。
- **一般化:** 幾何確率。配置空間の面積のうち「交わる」領域の比。\(L=D\) なら \(\dfrac{2}{\pi}\)。針が短い \(L<D\) なら \(\dfrac{2L}{\pi D}\)。ビュフォンの針。モンテカルロの原型。
- **仮定:** 三角関数の積分は、図の面積として見せる。既知でなければ短く導入する。

### 15. 酔歩は出発点に戻るか
- **slug:** `015_random_walk_return`
- **問い:** 直線上を毎ステップ左右へ等確率で歩く。いつかは原点に戻るか。平面、空間ではどうか。

- **試行:** 数直線上で「\(a\) から半径 \(\varepsilon\) 以内」という集合（開区間）を考える。#145 のタクシー距離でも同じような「近さの範囲」が作れることを確認する。
- **一般化:** 開集合という考え方（位相の芽）。「近い」を集合の言葉で定義すると、#31 の中間値の定理のような結果を、より一般的な空間でも議論できるようになる。
- **仮定:** #31, #145 の考え方を本編で再導入。厳密な位相空間の公理は扱わない。

### 147. 無限にも大きさの違いがあるのはなぜか
- **slug:** `147_cardinality_of_infinities`
- **問い:** #30 で実数は自然数より「多い」と分かった。では、実数の部分集合をすべて集めた集まりは、実数そのものよりさらに「多い」のか。
- **試行:** #30 の対角線論法を思い出し、今度は「集合の部分集合の集まり」に同じ論法が使えるかを、小さい有限集合（3個の要素）の部分集合の個数（\(2^3=8\)）から考え始める。
- **一般化:** カントールの定理（ある集合の部分集合全体は、元の集合より真に大きい）。無限の階層が無限に続くという驚き。
- **仮定:** #30 の対角線論法を本編で再導入。

### 148. 「正しいが証明できない」文はありうるか
- **slug:** `148_godel_incompleteness_intuition`
- **問い:** 数学のどんな正しい文にも、証明の手順を追えば「証明できる」はずだ、と思うのは間違っているのか。
- **試行:** 「この文は証明できない」という自己言及的な文を考える。この文が証明できるとしたら何が矛盾し、証明できないとしたら何が起きるかを、#45 の「止まるか判定する機械」と似た構造で追う。
- **一般化:** ゲーデルの不完全性定理（厳密な構成はせず、自己言及のパラドックスとしての直感を伝える）。数学の体系には限界があるという事実。
- **仮定:** #45 の自己言及的な構造の考え方（本編で導入、他の回を必須にしない）。

### 149. コンピュータでも解けない数学の問題はあるか
- **slug:** `149_undecidable_math_problems`
- **問い:** ある種の方程式に整数解があるかどうかを、原理的に判定できるアルゴリズムは存在するか。
- **試行:** 簡単な方程式なら整数解の有無を判定できる。しかし変数や次数を増やしていくと、判定の手順自体が「終わらない」可能性に気づく（#45, #148 と同じ構造）。
- **一般化:** 決定不能な問題（ヒルベルトの第10問題の結論を紹介する程度）。数学の問題の中には、アルゴリズムで解けないことが証明されているものがある。
- **仮定:** #45 の停止問題の考え方を本編で再導入。

### 150. 一周する道路のガソリンスタンド巡り、どこから出発しても成功する場所は必ずあるか
- **slug:** `150_gas_station_extremal_principle`
- **問い:** 円環状の道路にガソリンスタンドが何箇所かあり、それぞれ補給できる量と、次のスタンドまでに使う量が決まっている。合計では燃料が足りるとき、どこから出発してもガス欠にならずに一周できる出発点は必ずあるか。
- **試行:** 適当な出発点から一周をシミュレーションすると、途中でガス欠になる場合がある。出発点を変えるたびに結果が変わることを確認したあと、各地点までの「貯まり方」に注目してみる。
- **一般化:** 極値原理。全体の「貯まり方」が最も少なくなる地点（最小値を取る場所）から出発すれば、そこから先は一度も負にならないことが示せる。「一番極端な場所に注目する」という、多くの証明に共通する考え方。
- **仮定:** 数列の部分和。累積の考え方。
