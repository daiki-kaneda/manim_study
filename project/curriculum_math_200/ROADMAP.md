# 数学 200本カリキュラム ロードマップ

高校数学〜大学数学を対象にした、**数学単独で200本**の動画カリキュラムの構成表です。
`project/curriculum_algorithm_200/ROADMAP.md`（アルゴリズム200本）とは独立したシリーズです。

## 前提条件

- **本数**: 200本（数学のみ）
- **1本の長さ**: 5〜10分
- **制作ツール**: Manim（Python） / **言語**: 日本語（`manim_math/japanese.py` の `ja_text` / `ja_tex` を継承利用）
- **レベル**: 高校数学 〜 大学数学
- **ナレーション / BGM / 背景**: 今回のロードマップでは対象外（後続フェーズで検討）
- **状態**: 全て `未着手`（構成案であり、実装はこれから）

## 依存関係・視聴順の指針

- **Part A（高校数学）**は数I・A・II・B・III・Cの標準的な学習順に対応。A1→A14の順に前提知識が積み上がる。
- **Part B（大学数学）**はPart Aの完了を前提とする。B1（微積分の深化）とB3（線形代数）は並行して視聴可能。
- B2（多変数微積分）はB1・B3の後に置く。B4（常微分方程式）はB1・B3の後。
- B5（確率論・統計学）はA8（高校の確率）とB1（極限）を前提とする。
- B8（複素解析）はA12（複素数平面）とB1・B2を前提とする。B9（代数学）はB3（線形代数）を前提とする。
- B10（総合・発展トピック）は最終章として、各章の内容を組み合わせて扱う。

## 制作方針（今後の実装に向けたメモ）

- 既存の日本語ヘルパー `manim_math/japanese.py`（`ja_text`, `ja_tex`, `JapaneseScene`）を継承利用する。
  ただし本シリーズは1本5〜10分と長いため、既存の `PacedScene`（30〜60秒想定、`motion_scale=2.5`）は使わず、
  新たに `LessonScene`（仮称、`motion_scale=1.0` 程度）のような基底クラスを別途用意するのが妥当。
- 日本語は `ja_text` で表示し、`MathTex` / `ja_tex` 側には日本語を混在させない方針を踏襲する。
- ディレクトリ構成は既存の `project/math/` に合わせ、例えば
  `project/curriculum_math_200/{A|B}_<番号3桁>_<スラッグ>/{scene.py, storyboard.md}` のような形を想定。
- 1本あたりの構成は「見出し→具体例の提示→図解・アニメーションによる直感→定義/定理の提示→導出→まとめ」の6段構成を目安にし、
  5〜10分の尺を待機時間ではなく可視化・途中式のアニメーションで埋める。
- ナレーション・BGM・背景（色/テーマ）は本ロードマップの対象外。字幕・音声・配色は制作フェーズで別途検討する。
