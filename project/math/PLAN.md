## 1 本の作業フロー

1. `storyboard.md` に秒表を書く
2. `scene.py` を実装（`JapaneseScene` を継承）
3. `manim -pql ...` で確認
4. `-pqh` で書き出し、BGM を載せてアップロード

チェック: 日本語は `ja_text`（`MathTex` に日本語を入れない） / `Axes.plot` に bound method を渡さない / 最終フレームが結論と一致 / はみ出しなし。

尺は `JapaneseScene.beat` で調整（デフォルト 3 秒）。
